# 辉烬登录修复（Windows）

> 作者说明：暂时更新到 2026/11/5，用于修复这个苟延残喘的游戏在（2026/10/1 之后的）新手机上下载后的登录问题。后续可能随着游戏服务器的进一步停摆，更新更多的补充功能，如果有兴趣的话也可能变成独立客户端。

唯一入口是 `apply.bat`，仅依赖 Windows 自带的 `certutil` 和 ADB，不需要 Python、PowerShell 或额外运行库。

适用于 **Root、`com.kiif.huijin` 1.6.0（versionCode 7）、HotCode 1.0.27、安卓主用户 0**。安装前已缓存该热更新版本的资源清单。补丁处理登录约 46% 时 OSS 存档下载失败的问题；用户已确认，模拟器使用该补丁和原始模板后保留了此前进度。其他实体手机尚未实测。

## 使用

将 `adb.exe` 加入 PATH，或把 Android Platform Tools 的 `adb.exe` 及其配套 DLL 放在 `apply.bat` 旁。手机开启 USB 调试并授权电脑、允许 Root，然后**双击 `apply.bat`**：

- 只有一台设备时自动使用该设备。
- 多台设备时列出编号、序列号和状态，输入编号并回车选择。
- 未检测到设备时显示提示；未授权或离线设备也会显示，但无法执行修复。
- 无论成功、失败或已修复，结束时都会 `pause`，按任意键后才关闭窗口。

也保留可选的命令行指定方式，例如已连接的指定模拟器：

```bat
apply.bat 127.0.0.1:16448
```

脚本只操作自动确定的唯一设备或用户选中的设备，不操作其他手机，也不建立网络 ADB 连接。

脚本会验证本地补丁 SHA-256、游戏版本、Root 和手机现有文件；修改前保存原文件到 `backups/随机编号/`，随后停止游戏、写入两个缓存文件、拉回检查哈希并启动游戏。写入失败会自动尝试恢复原文件；失败备份必须保留。已安装相同补丁时显示结果并暂停，不重启游戏。

## 附带文件

- `payload/hotfix-patched.bundle`：与模拟器实际使用文件一致的补丁，SHA-256 为 `e7b5da492dcac2384a2df5e5fac23ed07cfe95f8ecccb5ec0dd3cc5a7d8b1757`。
- `payload/hotfix-info.bin`：对应缓存元数据，补丁保持原长度和 CRC32。
- `payload/OriginSave.es3`：从原 APK 提取的预置模板，供保留和核对；脚本不直接写入任何账号的 `Save.es3`。补丁在账号存档缺失时使用游戏 APK 内相同模板，保留已有账号存档并关闭其云端上传。

只有 apply 功能；不提供其他命令、APK 修改或本地镜像服务。它不处理版本接口不可用、账号认证失败或游戏服务器停用等独立故障。原 Python 工具保留在 Git 历史提交 `e66b18f`。

当前批处理通过 Windows CMD 的 7 种模拟 ADB 场景：已修复、正常写入、缓存缺失、写入失败回滚、未知文件拒绝、无 Root 拒绝、本地补丁损坏拒绝；同时检查含空格和 `!` 的目录路径及存档保留。该批处理尚未在实体手机实测。

交互流程另通过 7 种模拟场景：单设备、多设备选择、无效编号后重选、特殊字符输入拒绝、无设备、单台未授权设备、混合状态设备选择；检查目标设备隔离与最终暂停。
